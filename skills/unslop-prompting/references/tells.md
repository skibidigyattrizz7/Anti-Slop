# Prompt tells (dated)

last_verified: 2026-11-19 against the owner's original skill. The Infinity-Chat figures and the verbalized sampling claim are the owner's cited sources; the sampling gains are reported, not guaranteed, and vary by model.
Re-check: tool-specific advice every 3 months, everything after a major model release.

A tell is a reason to rework a prompt, never proof of anything. A prompt with several tells is likely to return the average answer.

## Structure

| Tell | Fix |
|---|---|
| No goal, no reader | Add what it is for and who uses it |
| Fewer than 3 concrete details | Ask the user for names, numbers, constraints |
| Adjective pile ("fun, engaging, modern, professional") | Pick one direction and add one example |
| No example | Paste a sample or describe a good and a bad one |
| "Be creative" or "be original" with nothing named | List the default to avoid and why |
| Length and format left open | State them exactly |
| One answer requested when variety matters | Ask for three different takes, pick the least generic |
| User facts paraphrased or cut | Put each in, in the user's own words |
| Re-rolling the same prompt | Keep the best draft and say what to change |

## Words and phrases

Count only in clusters:

- "make it good / unique / creative / professional / engaging"
- "act as a world-class expert", "you are the best..."
- "high quality", "stunning", "masterpiece", "ultra detailed" with nothing specific behind them
- "think outside the box"

Fix by replacing each with a real detail, constraint or example.

## Default plots to name

Stories: lighthouse keepers, "Elara", "Luna", "Max", magic wands, a lesson in the last line. Images: glowing orbs, teal and orange, generic neon cityscapes. Naming the default beats "be original". These lists age fast; check them against what the tool actually returns.

## Guards

- Do not blame the user. Ask for the missing facts.
- A prompt cannot guarantee different outputs. Do not claim it.
- Do not add facts to make a prompt look specific.
- A tool may require its own syntax (image tags, system prompt fields). Keep the facts, follow the syntax.
