# Report tells (dated)

last_verified: 2026-11-17 against `research_notes/` (slides_reports_dataviz.md) and the owner's ai-signs list (Oct 2026).
Re-check: structure tells every 6 months, anything citing a news case after each new report on fabricated references, everything after a major model release.

A tell is a reason to rework something, never proof of who made it. Many people write vaguely too.

## Structure (strongest)

| Tell | Fix |
|---|---|
| Source does not exist, or exists but does not say the cited thing | Open it. Replace with a real source or cut the claim |
| Source copied from a search snippet, page never opened | Open the page and find the passage |
| Number with no link, date or baseline in its paragraph | Add the source and date, or delete the number |
| Fake precision (47.3%) where the source gave a range | Quote the range |
| Name of a framework or product with no independent trace | Search for it. No trace, no use |
| Same skeleton every time: overview, key factors, challenges, outlook, conclusion | Order by the reader's question, answer first |
| Confident vagueness: no sample, scope, date or uncertainty | Add them, or say "not known" |
| Adjectives in place of figures ("significant growth") | Figure, baseline, date |
| Closing summary that repeats the body | End on recommendation and decision needed |
| Chart described without reading axes or units | Read the axes first, then describe |

## Slides and charts

| Tell | Fix |
|---|---|
| Titles are topic labels ("Market overview") | Sentence claim as title; titles alone tell the story |
| Four to seven same-weight bullets | One message per slide |
| Stock layout: gradient, icon row, three symmetric cards | Let layout follow content (table, sequence, paired bar) |
| Default chart: rainbow colours, many pie slices, gridlines everywhere, no unit or source | See `craft-charts.md` |
| Bars that do not start at zero | Start at zero |

## Words (expire fast)

Vague attribution: "studies show", "experts agree", "research suggests", "many believe". Trend filler that fits any topic: "growing rapidly", "increasingly important", "plays a crucial role". Count in clusters; one means nothing.

## Peer review text

Per ICLR 2026 analyses (owner's list): long filler reviews, generic weaknesses, many bullet questions, a score that does not match the text. Check invented or mismatched citations one by one.

## Guards

- Detector labels are weak evidence, especially on polished or formal text.
- Formal and non-native writing is not a tell.
- Quotations and passages that discuss a phrase are exempt.
- Never tune a report to beat a detector.
